## 2026-07-22 - [Broken Access Control on Internal Edge Functions]
**Vulnerability:** Internal-only/administrative methods (such as `SERVICE_METHODS` in `google-calendar`, sentiment analysis in `analyze-whatsapp-sentiment`, and Whisper transcription in `transcribe-whatsapp-audio`) were accessible via public HTTP invocation without verifying if the caller possesses the `SUPABASE_SERVICE_ROLE_KEY`. This could result in unauthorized administrative task execution or OpenAI/Whisper quota drain by malicious external requests.
**Learning:** Edge Functions intended for platform-to-platform or service-to-service calls do not inherit automatic authentication or sandbox isolation and must manually validate incoming requests. Relying on function-to-function invocation without checking the Authorization header results in a broken access control vulnerability.
**Prevention:** Always verify incoming request headers using `isServiceRole(req)` at the entry point of administrative or service-role Edge Functions, and reject any requests missing the service role key with a 401 Unauthorized response.
