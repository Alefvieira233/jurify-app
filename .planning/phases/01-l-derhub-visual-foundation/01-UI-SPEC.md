## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, status dot spacing |
| sm | 8px | Sidebar nav item vertical padding, button icon gap |
| md | 16px | Default horizontal padding in cards, TopBar horizontal gaps |
| lg | 24px | Sidebar section spacing, page header bottom margin |
| xl | 32px | Page content top padding, main layout horizontal padding |
| 2xl | 48px | Major section breaks between page blocks |
| 3xl | 64px | Full-page empty state vertical centering offset |

Exceptions:
- Touch targets (TopBar icon buttons, avatar): minimum 44px height — use `h-11` (44px) on clickable icon containers
- Sidebar width: 220px fixed (not a spacing token, a layout dimension)
- TopBar height: 56px fixed (`h-14`)
- Breadcrumbs: `px-6 pt-4 pb-1` (follows existing implementation — source: Breadcrumbs.tsx)

## Typography

Font family: `Inter, system-ui, -apple-system, sans-serif` (matches tailwind.config.ts `fontFamily.sans`)

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Sidebar nav labels, dropdown items, description text |
| Label | 12px | 400 (regular) | 1.4 | Breadcrumbs, status badges, section headers (uppercase tracking-wide) |
| Heading | 16px | 600 (semibold) | 1.4 | TopBar workspace name, card titles, page section titles |
| Display | 20px | 600 (semibold) | 1.2 | Reserved for Phase 2+ page headings — not used in Phase 1 |

Weights used in Phase 1: **400** (regular) and **600** (semibold) only.

Breadcrumb specifics: 12px, weight 400 for non-active crumbs; 12px, weight 500 (`font-medium`) for the active (last) crumb. Source: Breadcrumbs.tsx existing implementation.

## Color

Light mode (`:root`) — primary theme for Phase 1:

| Role | HSL | Hex approx | Usage |
|------|-----|------------|-------|
| Dominant (60%) | 0 0% 100% | #ffffff | Page background (`--background`), sidebar background, TopBar background, card surfaces |
| Secondary (30%) | 220 14% 96% | #f1f2f5 | Muted backgrounds (`--muted`, `--secondary`), sidebar hover state, input backgrounds, inactive tab backgrounds |
| Accent (10%) | 217 91% 60% | #3b82f6 | Active sidebar nav item text + left border, primary buttons, ring focus, TopBar notification badge, active state indicators |
| Destructive | 0 84% 60% | #f03e3e | Logout button hover, destructive dialog confirm button |

**Accent reserved for:** active sidebar nav item (text + `border-l-2`), primary `<Button>` variant, focus ring (`--ring`), unread notification badge count, and TopBar avatar border on focus. Never use accent on passive/hover states — use secondary (gray-100) for hover backgrounds.

**Accent token correction (Phase 1 Task 1):** Update `--accent` in `:root` from `217 91% 97%` (blue-50) to `220 14% 96%` (neutral gray-100, same as `--secondary`). Update `--accent-foreground` from `217 91% 45%` to `222 47% 11%` (dark foreground). This changes `hover:bg-accent` on sidebar nav items from a blue tint to a neutral gray — correct for the LíderHub white/blue design.

**Sidebar accent tokens** — also update in Phase 1:
- `--sidebar-accent`: change from `217 91% 97%` (blue-50) to `220 14% 96%` (neutral)
- `--sidebar-accent-foreground`: change from `217 91% 45%` to `222 47% 11%`

**Dark mode:** `.dark` block is left entirely unchanged (Lex Obsidian theme is complete and approved). Source: RESEARCH.md gap analysis.

Border color: `hsl(220 13% 91%)` (`--border`) — used on TopBar bottom border, sidebar right border, card outlines.

## Interaction Contracts

### TopBar — Workspace Selector

- Trigger: Click on "Jurify" workspace name text in TopBar left area
- Component: `<DropdownMenu>` from shadcn
- Dropdown width: 200px minimum
- Items: Current workspace (checked state), future workspaces (disabled/greyed with "Em breve" label)
- Current workspace item: semibold weight, blue checkmark icon (lucide `Check`)
- Close: Click outside or Escape key (Radix default)
- No keyboard navigation changes required beyond Radix defaults

### TopBar — Avatar Dropdown

- Trigger: Click on `<Avatar>` button in TopBar right
- Component: `<DropdownMenu>` from shadcn
- Items: "Minha Conta" (links to /configuracoes?tab=perfil), separator, "Sair" (calls logout)
- "Sair" item: destructive text color (`text-destructive`)
- No confirmation dialog for logout — direct action (logout is reversible via login)
- Close: Click outside or Escape key

### Sidebar — Search Bar

- Current: `bg-black/20` (broken on white)
- Corrected: `bg-muted` (`hsl(220 14% 96%)`) with `hover:bg-muted/80` transition
- Placeholder text: "Buscar..." (12px, muted-foreground color)
- Click behavior: unchanged — triggers GlobalSearch (Ctrl+K)

### Sidebar — Navigation Active State

- Active item: `text-primary` (blue-500) + `border-l-2 border-primary` + `bg-primary/5`
- Hover (inactive): `hover:bg-accent` — after token fix this becomes neutral gray hover
- Transition: `transition-colors duration-150`

### Breadcrumbs

- Hidden on `/` and `/home` routes (existing behavior — keep)
- Separator: `<ChevronRight>` from lucide, 14px, muted-foreground color
- Non-active crumbs: 12px, weight 400, `text-muted-foreground`, clickable (navigate back)
- Active (last) crumb: 12px, weight 500, `text-foreground`, not clickable

## Copywriting Contract

Phase 1 is a visual/structural phase — no new user-facing data flows or empty states. Copywriting below covers the new interactive elements introduced.

| Element | Copy |
|---------|------|
| TopBar workspace selector trigger label | Current workspace name (dynamic) — never hardcoded "Jurify" |
| Workspace dropdown — current workspace | "{workspace name}" with check indicator |
| Workspace dropdown — future item | "Em breve" (disabled) |
| TopBar avatar tooltip | "Minha conta" |
| Avatar dropdown — account item | "Minha Conta" |
| Avatar dropdown — logout item | "Sair" |
| Sidebar search placeholder | "Buscar..." |
| Sidebar referral CTA heading | "Indique Jurify" |
| Sidebar referral CTA sub-label | "Ganhe R$200 por indicação" |
| Notifications bell — no unread | No badge rendered (bell icon only) |
| Notifications bell — with unread | Numeric badge (e.g. "3") capped at "99+" |

No empty states in Phase 1 — layout scaffolding only.
No error states introduced — no new data fetching.
No destructive confirmation dialogs — logout is direct (no confirm).
