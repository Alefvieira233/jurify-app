**SEC-01 — create-portal-session (open redirect fix):**
After `const { returnUrl } = await req.json()`, add return URL validation matching the pattern already used in `create-checkout-session/index.ts` lines 58-80. Define `allowedOrigins` array:
```typescript
const origin = req.headers.get('origin') || '';
const allowedOrigins = [
  origin,
  'https://jurify.vercel.app',
  'https://jurify-app.vercel.app',
  'https://jurify.com.br',
].filter(Boolean);

const isValidReturnUrl = (url: string): boolean => {
  try {
    const parsed = new URL(url);
    return allowedOrigins.some(o => parsed.origin === o);
  } catch {
    return false;
  }
};
```

**SEC-05 — HTML-escape all template data:**
Add an `escapeHtml` utility at the top of `send-email/index.ts`, before the template definitions:
```typescript
function escapeHtml(str: string | undefined | null): string {
  if (!str) return '';
  return str
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#39;');
}
```

In the `buildEmailContent` function, wrap EVERY `data.*` interpolation inside HTML templates with `escapeHtml()`. For example:
- `${data.name}` becomes `${escapeHtml(data.name)}`
- `${data.plan_name}` becomes `${escapeHtml(data.plan_name)}`
- `${data.amount}` becomes `${escapeHtml(data.amount)}`
- `${data.period}` becomes `${escapeHtml(data.period)}`
- `${data.alert_message}` becomes `${escapeHtml(data.alert_message)}`

Do NOT escape `data.reset_url` or `data.invoice_url` when used in `href` attributes (URLs need to stay as-is for links to work), but DO escape them when displayed as visible text (if any).

**Important:** In `textBody` fields, do NOT apply `escapeHtml` — plain text does not need HTML escaping.
