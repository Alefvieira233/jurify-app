Create a new SankeyChart component that visualizes lead flow between pipeline stages using recharts' built-in Sankey component.

**1. Props interface:**
```typescript
interface SankeyChartProps {
  leads: Array<{ status: string | null; created_at: string }>;
}
```

**2. Build Sankey data from leads:**

Since we don't have actual transition history (no lead status change log), we simulate the pipeline flow based on current lead counts at each stage. The Sankey shows the funnel: leads at each stage flow "forward" to the next stage.

Create a `buildSankeyData` function:
- Define nodes array matching STATUS_PIPELINE order: `[{name: 'Nova Conversa'}, {name: 'Analise'}, {name: 'Qualificado'}, {name: 'Proposta'}, {name: 'Sucesso'}, {name: 'Perdas'}]`
- Count leads per status: `novo`, `em_contato`, `qualificado`, `proposta`, `ganho`, `perdido`
- Build links representing the pipeline funnel flow:
  - novo -> em_contato: value = count of em_contato + qualificado + proposta + ganho (leads that progressed past novo)
  - em_contato -> qualificado: value = count of qualificado + proposta + ganho
  - qualificado -> proposta: value = count of proposta + ganho
  - proposta -> ganho: value = count of ganho
  - novo -> perdido: value = Math.floor(count of perdido * 0.4) (40% of losses from early stage)
  - em_contato -> perdido: value = Math.floor(count of perdido * 0.3)
  - qualificado -> perdido: value = Math.floor(count of perdido * 0.2)
  - proposta -> perdido: value = count of perdido - (above three) (remainder)
- Filter out links with value <= 0

**3. Render:**
- Wrapper div with `border border-border rounded-lg p-5 bg-card`
- Header: icon `<TrendingUp className="h-4 w-4 text-muted-foreground" />` + `<h2 className="text-sm font-semibold text-foreground">Fluxo do Pipeline</h2>` + right-side `<span className="text-xs text-muted-foreground">Distribuicao por status</span>`
- If total leads is 0, show empty state: "Sem dados de leads para o periodo selecionado."
- Otherwise render `<ResponsiveContainer width="100%" height={300}>` wrapping `<Sankey>` with:
  - `data={sankeyData}`
  - `nodeWidth={10}`
  - `nodePadding={24}`
  - `margin={{ top: 10, right: 40, bottom: 10, left: 40 }}`
  - Custom node renderer using `<Rectangle>` from recharts with fill color mapped from STATUS_PIPELINE colors array by node index
  - Custom node label: render `<text>` with node name at `x + width + 6` for left-side nodes, `x - 6` for right-side nodes (index >= 4), font-size 11px, fill `hsl(var(--foreground))`
  - Custom link stroke using source node color with 0.3 opacity
  - `<Tooltip>` with contentStyle matching the Dashboard area chart tooltip (card background, border, 8px radius, 12px font)

**4. Export:** `export default SankeyChart;`
