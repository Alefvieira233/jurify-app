# Story 3.2: Consistencia UX, Mobile e Navegacao

## Status: Draft
## Sprint: 3
## Estimativa: 38 horas
## Prioridade: P1/P2

## Descricao

Tornar 5 tabelas criticas responsivas para mobile (pre-requisito para publicar o app Capacitor), adotar o componente EmptyState em 25 features que usam markup ad-hoc, ativar persistencia de rascunho em 5 formularios criticos (evitando perda de dados em navegacao acidental), e tornar breadcrumbs clicaveis. Esta story melhora a saude UX de 7/10 para ~8.5/10 e viabiliza a publicacao do app mobile.

## Notas Tecnicas

### ResponsiveTable Pattern
```tsx
const ResponsiveTable = <T,>({ columns, data, mobileCardRenderer, ...props }: ResponsiveTableProps<T>) => {
  const isMobile = useIsMobile();

  if (isMobile) {
    return (
      <div className="space-y-3">
        {data.map((item, i) => (
          <Card key={i} className="p-4">
            {mobileCardRenderer(item)}
          </Card>
        ))}
      </div>
    );
  }

  return <DataTable columns={columns} data={data} {...props} />;
};
```
