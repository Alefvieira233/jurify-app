# Story 3.3: Qualidade de Codigo e State Management

## Status: Draft
## Sprint: 3
## Estimativa: 24 horas
## Prioridade: P2

## Descricao

Centralizar query keys em um factory pattern (73 hooks com chaves inline), substituir cores hardcoded por design tokens (33 ocorrencias que quebram dark mode), eliminar escape hatches de tipagem (`supabaseUntyped`), e consolidar rate limiters duplicados. Esta story reduz a complexidade acidental do codigo e melhora a velocidade de desenvolvimento em ~15% para features que tocam estas areas.

## Debitos Incluidos

- **DEB-020:** Query key factory pattern ausente (8h) -- MEDIUM
- **DEB-027:** Hardcoded color values vs design tokens (8h) -- MEDIUM
- **DEB-022:** supabaseUntyped escape hatch em uso (4h) -- MEDIUM
- **DEB-029:** Rate limiting duplicado -- consolidacao (4h) -- MEDIUM

## Notas Tecnicas

### Query Key Factory Benefits
- Invalidacao granular: `queryClient.invalidateQueries({ queryKey: queryKeys.leads.all })`
- Autocomplete: TypeScript infere os keys disponiveis
- Prevencao de colisao: keys com namespace
- Rastreabilidade: todas as keys em 1 arquivo
