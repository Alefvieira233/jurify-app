# Story 4.1: Performance Frontend e Virtual Scrolling

## Status: Draft
## Sprint: 4
## Estimativa: 30 horas
## Prioridade: P2

## Descricao

Aplicar React.memo em componentes de lista para eliminar re-renders desnecessarios, implementar virtual scrolling em listas com 500+ items (apenas MessageView usa atualmente), e migrar chamadas diretas ao Supabase em componentes para hooks padronizados com React Query cache. Esta story prepara o frontend para escalar ate 100+ clientes sem degradacao de performance visivel.

  ```typescript
  const useVirtualList = <T>(options: {
    items: T[];
    estimateSize: number;
    overscan?: number;
  }) => {
    const parentRef = useRef<HTMLDivElement>(null);
    const virtualizer = useVirtualizer({
      count: options.items.length,
      getScrollElement: () => parentRef.current,
      estimateSize: () => options.estimateSize,
      overscan: options.overscan ?? 5,
    });
    return { parentRef, virtualizer };
  };
  ```

## Notas Tecnicas

### React.memo Pattern
```tsx
const LeadRow = React.memo(({ lead, onEdit, onDelete }: LeadRowProps) => {
  return (
    <TableRow>
      <TableCell>{lead.nome}</TableCell>
      {/* ... */}
    </TableRow>
  );
}, (prevProps, nextProps) => {
  return prevProps.lead.id === nextProps.lead.id
    && prevProps.lead.updated_at === nextProps.lead.updated_at;
});
```

### Virtual Scrolling Pattern
```tsx
const VirtualizedList = ({ items }: { items: Lead[] }) => {
  const { parentRef, virtualizer } = useVirtualList({
    items,
    estimateSize: 52,
    overscan: 10,
  });

  return (
    <div ref={parentRef} className="h-[600px] overflow-auto">
      <div style={{ height: `${virtualizer.getTotalSize()}px`, position: 'relative' }}>
        {virtualizer.getVirtualItems().map(virtualRow => (
          <div
            key={virtualRow.key}
            style={{
              position: 'absolute',
              top: 0,
              transform: `translateY(${virtualRow.start}px)`,
              height: `${virtualRow.size}px`,
              width: '100%',
            }}
          >
            <LeadRow lead={items[virtualRow.index]} />
          </div>
        ))}
      </div>
    </div>
  );
};
```
