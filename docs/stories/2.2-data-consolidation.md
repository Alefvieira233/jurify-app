# Story 2.2: Alinhamento do Design System e Contraste

## Status: Draft
## Sprint: 2
## Estimativa: 9 horas
## Prioridade: P1

## Descricao

Centralizar STATUS_COLORS em um unico arquivo (source of truth), corrigir contraste de cores em badges de status para compliance WCAG AA, e adicionar indexes complementares. Atualmente, cores de status estao duplicadas em 8 arquivos com valores inconsistentes, e algumas combinacoes de cores falham o criterio de contraste 4.5:1. Esta story e a fundacao para a substituicao de hardcoded colors (Sprint 3) e para o alinhamento com CHECK constraints (Story 2.1).

## Debitos Incluidos

- **DEB-006:** STATUS_COLORS duplicado em 8 arquivos (4h) -- HIGH
- **DEB-048:** Contraste de cores em status badges (4h) -- MEDIUM
- **DEB-018:** Indexes complementares crm_followups (1h) -- LOW *(movido para Story 2.1 se preferivel)*

```typescript
export interface StatusConfig {
  label: string;
  color: string; // CSS custom property name
  icon?: string;
  bgClass: string;
  textClass: string;
}

export const STATUS_CONFIG: Record<EntityType, Record<string, StatusConfig>> = {

    novo_lead: {
      label: 'Novo Lead',
      color: 'status-novo-lead',
      bgClass: 'bg-[var(--status-novo-lead-bg)]',
      textClass: 'text-[var(--status-novo-lead-text)]',
    },
    // ...
  },
  // ...
};
```
