## Notas Tecnicas

### Error Handling Decision Tree
```
Query falhou?
  -> Pagina inteira depende da query? -> ErrorState com retry
  -> Parte da pagina? -> ErrorState inline ou toast
Mutation falhou?
  -> toast(toUserMessage(error))
Formulario invalido?
  -> Inline errors via Zod + FormMessage (aria-live)
```

### Reduced Motion Hook (se necessario para JS animations)
```typescript
const usePrefersReducedMotion = () => {
  const [prefersReducedMotion, setPrefersReducedMotion] = useState(
    window.matchMedia('(prefers-reduced-motion: reduce)').matches
  );
  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)');
    const handler = (e: MediaQueryListEvent) => setPrefersReducedMotion(e.matches);
    mq.addEventListener('change', handler);
    return () => mq.removeEventListener('change', handler);
  }, []);
  return prefersReducedMotion;
};
```
