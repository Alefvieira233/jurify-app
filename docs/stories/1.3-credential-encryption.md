## Notas Tecnicas

### OpenAI Key Rotation
A rotacao deve ser atomica: atualizar o secret primeiro, depois revogar a antiga. Se revogar antes, havera downtime do assistente IA.

### Index Strategy
O index `(conversation_id, timestamp DESC)` ja existe (migration 20260207) e cobre o padrao principal de chat. O novo index `(tenant_id, lead_id)` cobre queries de "mensagens por lead" usadas no CRM.

### N+1 Fix
```typescript
// ANTES: 4 queries sequenciais
const leads = await supabase.from('leads')...
const processos = await supabase.from('processos')...
const contratos = await supabase.from('contratos')...
const agendamentos = await supabase.from('agendamentos')...

// DEPOIS: Promise.all ou RPC
const [leads, processos, contratos, agendamentos] = await Promise.all([
  supabase.from('leads')...,
  supabase.from('processos')...,
  supabase.from('contratos')...,
  supabase.from('agendamentos')...,
]);
```
